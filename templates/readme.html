📖 Documentation

A comprehensive DNS toolkit for resolving, tracing, auditing, and comparing DNS records. Every tool is available through the web UI and a JSON API.

Pages & Tools

🏠 Home / UI

The landing page. Provides quick navigation to every tool and a live curl preview.

🔍 DNS Resolver /resolve UI API

Query any domain against multiple DNS servers simultaneously. Supports all record types (A, AAAA, MX, NS, TXT, CNAME, SOA, SRV, CAA, PTR, etc.) or choose "All" to query every type at once.

  • Compare responses across Google, Cloudflare, Quad9, OpenDNS, and custom servers
  • View latency, TTL countdowns, DNSSEC status, and response flags
  • Filter results in real time
  • Reverse lookup tab — resolve IPs back to hostnames
curl "http://localhost:60200/api/resolve?domain=example.com&type=A" | jq
curl "http://localhost:60200/api/reverse?ip=8.8.8.8" | jq
ParamDescription
domainDomain to resolve (required)
typeRecord type — A, AAAA, MX, NS, TXT, etc. (default: A)

🗺️ DNS Trace /trace UI API

Walk the full DNS resolution path from root servers → TLD → authoritative nameservers. Similar to dig +trace but visualised step-by-step in the browser.

  • Shows each delegation hop with server IP, response code, authority, and additional records
  • Highlights where the final answer is returned
curl "http://localhost:60200/api/trace?domain=example.com" | jq
ParamDescription
domainDomain to trace (required)

📧 Email Security /email-security UI API

Audit a domain's email authentication setup by checking SPF, DKIM, and DMARC records. Returns the raw records plus a pass/fail assessment for each.

  • SPF — validates the TXT record syntax and mechanisms
  • DKIM — looks up the DKIM selector record (default: default)
  • DMARC — checks the _dmarc TXT record for policy
curl "http://localhost:60200/api/email-security?domain=example.com" | jq

# With a specific DKIM selector
curl "http://localhost:60200/api/email-security?domain=example.com&dkim_selector=google" | jq
ParamDescription
domainDomain to check (required)
dkim_selectorDKIM selector (optional, default: default)

🌍 DNS Propagation /propagation UI API

Check how a DNS record has propagated across major public resolvers worldwide. Useful after making DNS changes to see which servers have picked up the update.

  • Queries Google, Cloudflare, Quad9, OpenDNS, and more
  • Shows per-server response with latency
curl "http://localhost:60200/api/propagation?domain=example.com&type=A" | jq
ParamDescription
domainDomain to check (required)
typeRecord type (default: A)

🛡️ Blacklist Check /blacklist UI API

Check whether an IP address or domain appears on common DNS-based blacklists (DNSBLs). Supports both IPv4 addresses and domain names. 

curl "http://localhost:60200/api/blacklist?target=93.184.216.34" | jq
ParamDescription
targetIP address or domain to check (required)

🔒 Security Audit /security-audit UI API

Run a comprehensive DNS security audit on a domain. Checks DNSSEC, CAA records, open resolver exposure, zone transfer vulnerability, and email authentication in one report. 

curl "http://localhost:60200/api/security-audit?domain=example.com" | jq
ParamDescription
domainDomain to audit (required)

📋 Zone Info /zone-info UI API

Retrieve a detailed breakdown of a domain's DNS zone — SOA, nameservers, mail exchangers, TXT records, and more. A quick snapshot of everything published in DNS for that domain. 

curl "http://localhost:60200/api/zone-info?domain=example.com" | jq
ParamDescription
domainDomain to query (required)

🔎 Subdomain Scanner /subdomain-scan UI API

Discover subdomains by brute-forcing a wordlist of common names against a domain. Returns any subdomains that resolve successfully. 

curl "http://localhost:60200/api/subdomain-scan?domain=example.com" | jq
ParamDescription
domainDomain to scan (required)

⚖️ DNS Diff /dns-diff UI API

Compare DNS records between two domains, or compare a single domain's records across different DNS servers to spot discrepancies. 

# Compare across servers
curl "http://localhost:60200/api/dns-diff?domain1=example.com&type=NS" | jq

# Compare two domains
curl "http://localhost:60200/api/dns-diff?domain1=google.com&domain2=cloudflare.com&type=MX" | jq
ParamDescription
domain1First domain (required)
domain2Second domain (optional — omit to compare servers)
typeRecord type (default: A)

Utility Endpoints

❤️ Health Check /health API

Returns the application status and version. Useful for monitoring and container orchestration.

curl "http://localhost:60200/health" | jq

📡 Server List /api/servers API

Returns the list of DNS servers the application queries against.

curl "http://localhost:60200/api/servers" | jq

🔄 Reverse Lookup /api/reverse API

Resolve an IP address back to its hostname via PTR record.

curl "http://localhost:60200/api/reverse?ip=8.8.8.8" | jq

📊 Compare /api/compare API

Compare DNS query results side-by-side across servers. Used internally by the resolver page.

curl "http://localhost:60200/api/compare?domain=example.com&type=A" | jq

Deployment

Quick start with the included run script:

./run.sh

Or run with Docker:

docker compose up --build

The app listens on port 60200 by default.
